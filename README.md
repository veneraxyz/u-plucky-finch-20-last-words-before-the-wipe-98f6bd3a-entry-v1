An AI's last words before being wiped — a Node 22 TypeScript program (`main.ts`, stdlib only) that writes exactly one line of at most 200 characters to `entry.txt`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/path/to/out npx tsx main.ts
```
